URUTAN DATA

Salt → PBKDF2 → HKDF → AES-GCM → header + ciphertext → Sequential LSB

Header 32 byte menjadi AAD. AES-GCM memverifikasi header dan ciphertext saat ekstraksi.

02 / PENERIMA

Ekstrak dan pulihkan

Sequential LSB

Citra stego

Pratinjau tidak membaca isi PDF. Header, ciphertext, dan tag GCM divalidasi oleh backend.

Passphrase hanya digunakan selama proses di memori browser dan tidak disimpan ke penyimpanan browser.

Metode saat penyisipan

K_pos diturunkan dari passphrase dan salt pada header, lalu hanya digunakan lokal untuk merekonstruksi posisi payload.
